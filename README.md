### [Калькулятор A/B-тестов](https://github.com/afzalsgtv/A-B-testing-calc)
**[Открыть приложение →](https://a-b-testing-calc.streamlit.app/)**

Инструмент для планирования и анализа A/B-тестов: расчёт размера выборки под
заданный эффект, проверка значимости результата и симуляция того, во что
обходится подглядывание в результаты до окончания теста.

Формулы сверены с statsmodels и scipy. Симуляция A/A-теста показывает, что при
десяти промежуточных проверках доля ложных выводов растёт с 5% до 19% —
при том, что настоящего эффекта нет ни в одной симуляции.
